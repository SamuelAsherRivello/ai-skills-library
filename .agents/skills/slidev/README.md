# Slidev Skills

Reusable workflows for the local Slidev documentation workspace: start and
verify the multi-deck landing page, translate presentation content into slides,
resynchronize decks with their template catalog, and apply a layout adjustment
consistently across selected slides.

| # | Name | Comment |
|---:|---|---|
| 1 | [Slidev Resync Templates Decks](./slidev-resync-templates-decks/SKILL.md) | Diagnose mapping drift and safely resynchronize declared template and deck metadata. |
| 2 | [Slidev Run](./slidev-run/SKILL.md) | Start and verify the Slidev landing page and its proxied decks. |
| 3 | [Slidev Slides to Content](./slidev-slides-to-content/SKILL.md) | Inspect the active Slidev deck and turn source slides into structured deck content. |
| 4 | [Slidev Sync Layout Across Deck Slides](./slidev-sync-layout-across-deck-slides/SKILL.md) | Apply an approved layout adjustment consistently to selected deck slides. |
