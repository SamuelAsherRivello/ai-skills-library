# Proposal coordinator naming

- Coordinator: `OS-ORC: {change}`, using the shared proposal-coordinator title format.
- Scope: this coordinator for one resolved proposal only. Delegate this chat to `$openspec-title-management`; never rename every project chat.
- Child OpenSpec workflows own their phase and progress titles. Record observed titles; each child owner delegates its own update to `$openspec-title-management` rather than being overwritten here.
- Read the shared [title contract](../../openspec-title-management.md) when available.
- Invoke the manager at execution start and after verified coordinator progress changes. Editing this skill never triggers a rename.
- The manager preserves a normalized user subject while rebuilding this coordinator's active prefix and verified suffix. Keep coordinating if naming is unavailable.
- Existing legacy project-wide naming ledgers are historical evidence, not authority to rename unrelated chats or repeat an old naming pass.
