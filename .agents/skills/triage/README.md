# Triage

Use these workflows to assess a codebase and plan or apply a focused
standardization or architectural improvement.

- [triage-analyze](./triage-analyze/SKILL.md): Assess the current codebase
  and identify the highest-value improvements.
- [triage-rearchitect](./triage-rearchitect/SKILL.md): Plan and apply one
  evidence-based architectural change.
- [triage-standardize](./triage-standardize/SKILL.md): Align the codebase
  with its approved project standards.
