# Proposal coordinator naming

- Coordinator: `OS-ORC: {change}`, using the shared proposal-coordinator title format.
- Scope: this coordinator for one resolved proposal only. Never rename every project chat.
- Child OpenSpec workflows own their phase and progress titles. Record observed titles; ask the owner to repair omissions rather than overwrite them.
- Read the shared [title contract](../../openspec-title-management.md) when available.
- Set the title at execution start, then update only if it still matches the last confirmed title applied by this workflow.
- Preserve human overrides, including after interruption or handoff. Editing this skill never triggers a rename.
- Use supported title tools, refresh immediately before writing and verify the outcome. Reconcile uncertain writes before retrying. Keep coordinating if naming is unavailable.
- Existing legacy project-wide naming ledgers are historical evidence, not authority to rename unrelated chats or repeat an old naming pass.
