# Library Management

Use these skills to manage independent copies of skills in the library,
global Codex installation, and the current project.

## Skills

| # | Name | Comment |
|---:|---|---|
| 1 | [ai-skills-library-move-global](./ai-skills-library-move-global/SKILL.md) | Move project-local skills to the global installation. |
| 2 | [ai-skills-library-move-project](./ai-skills-library-move-project/SKILL.md) | Move global skills into the current project. |
| 3 | [ai-skills-library-pull](./ai-skills-library-pull/SKILL.md) | Copy library skills to the global installation. |
| 4 | [ai-skills-library-push](./ai-skills-library-push/SKILL.md) | Copy global skills into the local library checkout. |
| 5 | [ai-skills-library-status](./ai-skills-library-status/SKILL.md) | Compare library, global, and project skill copies. |
| 6 | [ai-skills-library-welcome](./ai-skills-library-welcome/SKILL.md) | Confirm that the shared skills are available in the current scope. |
| 7 | [ai-skills-project-run-start](./ai-skills-project-run-start/SKILL.md) | Compatibility entry point for starting a project server. |
| 8 | [ai-skills-project-status](./ai-skills-project-status/SKILL.md) | Summarize current-project chats and their OpenSpec completion state. |
| 9 | [ai-skills-unarchive](./ai-skills-unarchive/SKILL.md) | Find and restore an archived Codex chat. |
