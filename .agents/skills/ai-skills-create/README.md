# Create

Use these explicit workflows to create a repository, build an application or
game from the shared template, or release a prepared repository.

## User Workflows

| # | Name | Comment |
|---:|---|---|
| 1 | [ai-skills-create-app](./ai-skills-create-app/SKILL.md) | Create a non-game React application from the shared repository template. |
| 2 | [ai-skills-create-game](./ai-skills-create-game/SKILL.md) | Create and publish a single-player or requested multiplayer browser game. |
| 3 | [ai-skills-create-github-repo](./ai-skills-create-github-repo/SKILL.md) | Create a repository from the shared template and prepare its checkout. |
| 4 | [ai-skills-create-playtest](./ai-skills-create-playtest/SKILL.md) | Guide a human through verifying a web application before release. |
| 5 | [ai-skills-release-version](./ai-skills-release-version/SKILL.md) | Release a template-compatible repository through its checked-in version workflow. |
