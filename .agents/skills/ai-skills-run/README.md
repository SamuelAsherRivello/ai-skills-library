# Run

Reusable workflows for starting, inspecting, and stopping existing local
projects without development-port collisions or unnecessary terminal windows.

| # | Name | Comment |
|---:|---|---|
| 1 | [Run configuration](./references/run-configuration.md) | Shared declaration and reconciliation policy for agent-agnostic project port ranges. |
| 2 | [Start](./ai-skills-project-run-start/SKILL.md) | Start one project-owned development server on a verified, range-bounded local port. |
| 3 | [Status](./ai-skills-project-run-status/SKILL.md) | Inspect ownership, route health, active ports, and optional cross-project overlaps. |
| 4 | [Stop](./ai-skills-project-run-stop/SKILL.md) | Stop only the confirmed project-owned server tree. |
