# AI Skills Library Catalog

Each skill is a self-contained, installable directory. These category catalogs
are a navigation aid; they do not change skill names or installer behavior.

## Categories

- [Create](./ai-skills-create/README.md): Create applications, games, and
  template-based releases.
- [Library Management](./ai-skills-library/README.md): Compare, copy, and move
  skills between the library, global installation, and projects.
- [Docker Sandbox](./docker-sandbox/README.md): Configure and inspect isolated
  Docker Sandbox environments.
- [OpenSpec](./openspec/README.md): Explore, plan, implement, and finalize
  repository changes through OpenSpec.
