# Triage Skills

Skills for evaluating a codebase's architecture, applying approved
standardization, and planning focused, evidence-backed refactors.

| # | Name | Comment |
|---:|---|---|
| 1 | [Triage Analyze](./ai-skills-triage-analyze/SKILL.md) | Assess a codebase's standardization and architecture health without changing it. |
| 2 | [Triage Rearchitect](./ai-skills-triage-rearchitect/SKILL.md) | Plan and apply one selected, evidence-backed architecture refactor. |
| 3 | [Triage Standardize](./ai-skills-triage-standardize/SKILL.md) | Align a codebase with its approved project, class, and AI-readiness conventions. |
