## Getting Started

### 1. Install Commands

**Prompt AI:**

```
Add these skills to your AI global skills:

- https://github.com/SamuelAsherRivello/ai-skills-library/
```

### 2. Update Commands

Over time the library may change with new features.

**Prompt AI:**

```
$ai-skills-library-pull all
```
